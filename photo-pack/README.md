# Realistic photo pack: CHAMP demo campaigns

Real photographs for every CHAMP donation-page layout, for the two demo charities (Lantern Trust: homelessness; Willowmere Hospice: hospice care, flower theme).
Each image is cropped to CHAMP's exact recommended size for its layout and was checked in the live page on desktop and phone.

| Layout | Size |
|---|---|
| Classic | 1600 × 600 |
| Compact | 1200 × 480 |
| Image left / Image right | 1120 × 1280 |
| Hero banner | 1920 × 600 |
| Immersive | 1920 × 1080 |

Use the existing logos in `../demo-campaign-images/` and `../hospice-flowers/`.
